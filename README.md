# Artemis

A small web project celebrating NASA's Artemis program — humanity's return to the Moon.

Live at [artemis.radman.dev](https://artemis.radman.dev).

## Running locally

You'll need Node and pnpm. Then:

```bash
nvm use
pnpm install
pnpm dev
```

To build and preview:

```bash
pnpm build
pnpm start
```

## Docs

Design and content notes live in [`docs/`](docs/), including screenshots and the original NASA source PDFs.
